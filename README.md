# 🛒 Retail Sales Dataset Query

A simple SQL project created in Databricks to explore and retrieve data from a retail sales dataset.

## 📌 Query Used
```sql
SELECT *
FROM retail.sales.dataset;
````

 Project Purpose

This query was used to:

* Retrieve all records from the dataset
* Practice basic SQL skills
* Explore data within Databricks

 Tools & Technologies

* SQL
* Databricks

 About

This project forms part of my journey in Data Analytics, where I am building practical skills in SQL, data exploration, and database management.
